### Security Sweep and Investigation Playbook
#### When to Use
This playbook is used when a security sweep indicates a MEDIUM or HIGH risk level, or when an investigation is required to assess the severity of a potential security incident.

#### Step-by-Step Procedure
1. **Run Security Sweep**: Use the `agents/security_sweep.py` tool to perform a security sweep and assess the current risk level.
2. **Review Security Sweep Report**: Review the report generated by the security sweep tool, which is stored in the `intel/reports` directory (e.g., `intel/reports/security-2026-07-10-09.md`).
3. **Identify Potential Incidents**: Identify potential security incidents from the report, including the number of incidents in the last 7 days and the total value of incidents.
4. **Run Investigation**: Use the `agents/investigate.py` tool to investigate potential security incidents.
5. **Review Investigation Report**: Review the report generated by the investigation tool, which is stored in the `intel/reports` directory (e.g., `intel/reports/investigation-2026-07-10-09.md`).
6. **Assess Severity**: Assess the severity of the potential security incident based on the investigation report.
7. **Update VAPE's Permanent Record**: Update VAPE's permanent record with the results of the investigation, including the verdict and any relevant metadata.

#### Quality Gates
* The security sweep tool must return a risk level of MEDIUM or HIGH before proceeding with an investigation.
* The investigation tool must generate a report that includes a verdict and relevant metadata.
* The investigation report must be reviewed and updated in VAPE's permanent record.

#### Limitations
* The security sweep tool may not detect all potential security incidents.
* The investigation tool may not be able to assess the severity of all potential security incidents.
* The playbook relies on the accuracy and completeness of the security sweep and investigation reports.

#### Tools Used
* `agents/security_sweep.py`
* `agents/investigate.py`
* `intel/reports` directory for storing security sweep and investigation reports

#### Example Use Case
* A security sweep indicates a MEDIUM risk level with 2 incidents in the last 7 days.
* An investigation is run using the `agents/investigate.py` tool, which generates a report indicating a potential security incident with a verdict of MEDIUM.
* The investigation report is reviewed and updated in VAPE's permanent record, including the verdict and relevant metadata.
