### 2. Truncated Trend Logic (Code Completeness)
*   **File**: `agents/macro_sweep.py`
*   **Function**: `compute_trend(fng, glob)`
*   **Finding**: The function definition is cut off abruptly at the end of the file (`Fas`). While this is partly an artifact of the digest builder's truncation, the docstring explicitly notes that the `prev_value` (yesterday's Fear & Greed reading) was historically discarded, leaving many days with a flat `NEUTRAL` trend even when momentum was clearly risk-on or risk-off.
*   **Remedy**: Ensure the momentum check is fully implemented. If `fng` is in the neutral zone (e.g., 40-60) but `fng - prev_value >= 10` (improving sentiment) or `fng - prev_value <= -10` (deteriorating sentiment), the trend should resolve to `RISK-ON` or `RISK-OFF` respectively instead of defaulting to `NEUTRAL`.

### Targeted Improvements

1.  **Robust Scraper Fallback for Google News Redirects**
    *   **File**: `agents/news_common.py`
    *   **Improvement**: Google News RSS links (Lane 1) redirect through `news.google.com`, and many target publishers block scraper traffic outright, causing `scrape_article_text()` to return empty results. To improve grounding quality for `news_reporter.py`, implement a fallback that extracts the clean publisher name and title from the RSS item, and runs a quick keyless search (via `skillforge.research.search`) to find alternative, scraper-friendly coverages of the same story when the primary redirect scrape fails.

2.  **Cross-Reference Patch Checks with Incident Forensics**
    *   **File**: `agents/mainnet_patch_check.py`
    *   **Improvement**: The script periodically verifies if known historical vulnerabilities (like `AgentNftV2::addValidator` missing access control) remain patched on-chain. This deterministic check can be made significantly more powerful by cross-referencing the target address against VAPE's own real incident forensics feed (`data/attack-feed.json`). If the contract being checked has a matching active incident or investigation CAUTION/REJECT verdict on record, escalate the patch check's output to `CRITICAL` immediately, as a live exploit may already be bypass-testing the supposed patch.
