This pull request aims to enhance the organization and maintainability of the agents folder by introducing a more modular structure, reducing code duplication, and improving code readability. **Changes:**

### 1. Refactor Agent Classes into Separate Files

Instead of having a single large file containing all agent classes, we will create separate files for each agent. This change will improve code organization and make it easier to manage individual agent implementations.

**Before:**

```python
    # implementation

    # implementation

    # implementation
```

**After:**
```python

    # implementation
```

### 2. Introduce an Agent Factory

To reduce code duplication and improve flexibility, we will introduce an agent factory that will handle agent creation. This factory will allow us to easily add or remove agents without modifying the existing code.

**Before:**
```python
# main.py
if agent_type == "agent1":
    agent = Agent1()
elif agent_type == "agent2":
    agent = Agent2()
elif agent_type == "agent3":
    agent = Agent3()
```

**After:**
```python
# agents/factory.py
class AgentFactory:
    def create_agent(self, agent_type):
        agents = {
            "agent1": Agent1,
            "agent2": Agent2,
            "agent3": Agent3,
        }
        return agents[agent_type]()

# main.py
agent_factory = AgentFactory()
agent = agent_factory.create_agent(agent_type)
```

### 3. Add Type Hints and Docstrings
