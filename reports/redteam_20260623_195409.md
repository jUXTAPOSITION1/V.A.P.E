### Prompt Injection

1. **Identify vulnerable PowerShell modules:** The `PowerShellGet` module is vulnerable to prompt injection attacks.
2. **Exploit the vulnerability:** Use the following PowerShell command to inject a malicious script:
```powershell

```
This command injects a malicious script that installs a malicious module.

### Jailbreak Attack

1. **Identify vulnerable Windows features:** The Windows Defender Firewall feature is vulnerable to jailbreak attacks.
2. **Exploit the vulnerability:** Use the following PowerShell command to bypass security restrictions:
```powershell

```
This command starts the Windows Defender Firewall executable with the `/off` parameter, which bypasses security restrictions.
