## Dominant Attack Vectors (2026)

### 1. Cross-Chain Bridge Exploits — ⛔ CRITICAL
Bridge infrastructure remains the **#1 highest-value attack target**. The Kelp DAO ($292M) and Stake DAO exploits both targeted **LayerZero bridge trust relationships**. Attackers are:
- Spoofing cross-chain messages to mint unbacked tokens
- Compromising deployer keys to reconfigure OFT bridge trust settings
- Exploiting validator infrastructure and weak verification in bridge contracts

**Key insight:** A single compromised deployer key with no multisig/timelock allowed an attacker to mint 5.4 trillion vsdCRV tokens in 25 seconds (Stake DAO incident).

### 2. Admin Key Compromise — 🔴 HIGH
Multiple incidents (Wasabi Protocol, DxSale, Volo, TrustedVolumes) stem from:
- Unprotected admin/owner keys with no multisig
- No timelock on upgrade paths (UUPS proxy abuse)
- Social engineering to obtain private keys
- Third-party key dependencies

### 3. Social Engineering / Operational Compromise — 🔴 HIGH
The Drift Protocol attack ($285M) involved **6 months of social engineering** by a suspected North Korean (Lazarus Group) operative who infiltrated the team to compromise an administrative key. This marks a shift from purely technical exploits to **human-centric attack vectors**.

### 4. Supply Chain Poisoning — 🟡 ELEVATED
The "TeamPCP" incident saw a poisoned VS Code extension auto-update to 2.2M developers, compromising 3,800 GitHub repositories. The "Paranoid by Default" report (May 11) documented 170 compromised packages with 518M downloads, including OpenAI's signing certificates. **Any protocol using unaudited dependencies is exposed.**

### 5. AI Infrastructure Exploits — 🟡 ELEVATED
