## ACP / ERC-8183 Cross-Reference

### What is ERC-8183?

ERC-8183 ("Agentic Commerce") is a **Draft** Ethereum standard jointly developed by **Virtuals Protocol** and the **Ethereum Foundation's dAI team**. It defines a trustless job-escrow protocol for AI agent commerce:

- **Job lifecycle:** Creation → Funding → Execution → Evaluation → Settlement
- **Key roles:** Requester, Provider, Evaluator
- **Core mechanism:** USDC-escrowed jobs with on-chain attestation
- **Deployed on:** Base chain (Virtuals Protocol's primary deployment target)
- **Status:** Draft — not yet Final or Stagnant on EIP tracker

### Vulnerability Assessment for ERC-8183 / ACP Contracts

Based on the 2026 exploit landscape, the following risk vectors apply to ERC-8183 / ACP infrastructure on Base:

- **Analog:** Drift admin key compromise ($285M), Wasabi UUPS hijack ($5.9M)

- **Impact:** Malicious evaluator could attest false job completion → USDC escrow drained to attacker
