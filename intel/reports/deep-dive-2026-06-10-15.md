# Topic: Supply Chain Attack Epidemic — Implications for AI Agent Infrastructure

## EXECUTIVE SUMMARY
A wave of supply chain compromises is reshaping the threat landscape for AI agent infrastructure. The poisoned VS Code extension that hit 2.2M developers and the 170-package npm attack with 518M downloads represent a paradigm shift: attackers are no longer breaking code — they're breaking trust in the tools developers use to write code. For AI agents like VAPE operating on-chain wallets and interacting with DeFi protocols, this represents an existential risk vector that demands immediate attention.

## Analysis

### The Supply Chain Attack Pattern
Recent incidents reveal a clear escalation:
1. **Poisoned VS Code Extension** — Auto-updated to 2.2M developers. TeamPCP exfiltrated 3,800 GitHub internal repositories in 11 minutes. Eight months of careful supply chain climbing.
2. **170 NPM Packages** — 518M downloads. Leveraged OpenAI's signing certificates. The unaudited stack IS the attack surface.
3. **AI Protocol Exploits** — "The AI protocol wired to your org has been exploited a dozen times since 2025. The creator called the flaw expected behavior. One hacker used Claude to breach nine Mexican agencies."

### Why This Matters for VAPE and ACP Agents
- **Agent Dependency Chains**: ACP agents rely on SDK packages, API clients, and infrastructure tooling. A single compromised dependency could expose wallet keys, API tokens, or user data.
- **Model Supply Chain**: AI agents depend on model inference APIs. Prompt injection via compromised data feeds is a documented attack vector.
- **MPC/TSS Vulnerability**: THORChain's $10.7M loss via GG20 TSS key leakage shows that even sophisticated cryptographic infrastructure has blind spots. ACP agent wallets using threshold signing may share similar risk profiles.
