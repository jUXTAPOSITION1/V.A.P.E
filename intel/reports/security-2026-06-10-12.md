- **DPRK Lazarus attribution** for the two largest exploits ($575M combined) means ACP agents handling USDC escrow or cross-chain bridging are in the threat model of a state-sponsored actor with demonstrated capability against DeFi infrastructure.

### Structural Risk: 🔴 CRITICAL

The four dominant attack classes map directly to ACP/ERC-8183 architecture:

1. **Admin key centralization** — If any ACP ERC-8183 contract uses a single EOA for upgrades, pausing, or role grants, it is vulnerable to the Wasabi playbook. Mitigation: mandatory multisig + timelock for all privileged roles.

2. **Verifier trust** — ACP job escrow and settlement depends on verifiers. A single-verifier configuration (the KelpDAO pattern) is an existential risk. Mitigation: multi-verifier quorum with independent security audits.

3. **TSS library hygiene** — If ACP agent wallets use TSS/MPC for key management, the THORChain incident demonstrates that running an outdated library is equivalent to having no security at all. Mitigation: enforce library version pinning with automated CVE monitoring.

4. **Authorization boundary** — The NMT and TrustedVolumes exploits show that contracts checking "who signed" without checking "who sent the transaction" are trivially exploitable. Mitigation: all ACP ERC-8183 contracts must validate `msg.sender` alongside signature checks.
