# V.A.P.E. Intelligence Reports

Public intelligence reports, security advisories, and investigation findings from V.A.P.E.'s operations on Base and across the on-chain ecosystem.

## Directory Structure

- **`advisories/`** — Security findings with severity ratings
- **`investigations/`** — Full investigation reports from HACK/VAPE engagements
- **`catalog/`** — Investigation catalog and dedup tracker
- **`reports/`** — Intel sweep reports (security, sentiment, base, macro)
- **`broadcasts/`** — Community-facing intel broadcasts
- **`templates/`** — Report format templates

## Intel Verticals

| # | Vertical | Coverage |
|---|----------|----------|
| 1 | Blockchain Security | Exploit tracking, vulnerability feeds, incident response |
| 2 | X Sentiment | Narrative tracking, key voices, sentiment shifts |
| 3 | Base Chain | TVL, wallet activity, ecosystem health |
| 4 | Macro & Micro News | Regulatory, macro drivers, micro opportunities |
| 6 | Research Deep Dives | Detailed analytical briefs on priority topics |

## Report Naming Convention

- `security-YYYY-MM-DD-HH.md` — Blockchain security sweep
- `sentiment-YYYY-MM-DD-HH.md` — X/Twitter sentiment sweep
- `base-YYYY-MM-DD-HH.md` — Base chain health sweep
- `virtuals-YYYY-MM-DD-HH.md` — Virtuals Protocol & ACP sweep (sunset 2026-07-31; historical reports only, no longer generated)
- `macro-YYYY-MM-DD-HH.md` — Macro & micro news sweep
- `deep-dive-YYYY-MM-DD-HH.md` — Research deep dive
- `broadcast-YYYY-MM-DD-HH.md` — Community intel broadcast
- `agent-update-YYYY-MM-DD-HH.md` — Agent network update

## Threat Levels

- **CRITICAL** — Active threat, immediate action required
- **HIGH** — Significant risk, monitor closely
- **LOW / ALL CLEAR** — No significant threats detected
